# Product Overview

## One-line definition

An AI-powered job intelligence platform that aggregates authorized job opportunities from multiple sources, eliminates duplicates, analyzes job requirements, matches them against a candidate's profile, identifies skill gaps, and provides an actionable job-search strategy.

## Real-world problem

Job seekers search across many fragmented platforms (LinkedIn, Naukri, Indeed, company career pages, ATS boards), manually read lengthy job descriptions, compare them against their own resume, try to identify missing skills, and decide what to apply to — largely by guesswork. Problems this creates:

- Opportunities are fragmented across sources
- The same job appears on multiple platforms
- Descriptions are long and hard to parse for real requirements
- Candidates don't know which jobs deserve priority
- Skill gaps are hard to identify objectively
- Candidates apply somewhat randomly
- Market-wide skill demand is invisible to an individual candidate

## Solution

An intelligence layer above job sources — not a replacement for them — that collects, normalizes, deduplicates, and AI-analyzes jobs, then compares them against a user's profile to produce an explainable match, a prioritized job list, identified skill gaps, and a market-aware career action plan.

## Target users

- **Freshers** — first technical job seekers
- **Early-career professionals** (~0–5 years) — seeking better opportunities
- **Career switchers** — e.g. Support Engineer → Cloud Engineer

## Initial domain

Technology roles only for v1: Software Engineer, Backend/Frontend/Full Stack Developer, DevOps Engineer, Cloud Engineer, SRE, Data Engineer, QA Engineer, Cybersecurity Engineer. Not every profession — scope is intentionally narrow.

## What this product is NOT

- Not a replacement for LinkedIn/Naukri/Indeed
- Not built around unauthorized scraping or bypassing platform restrictions
- Not an AI that arbitrarily decides match scores — code calculates, AI explains

## Differentiators

- Explainable match scores (not just a number)
- Job prioritization across sources
- Market-wide skill demand intelligence
- Career action engine translating skill gaps into a learning priority list
